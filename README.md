# VOX — Pro Mobile Video Editor

VOX is a browser-first mobile video editor. This upgraded build fixes the JavaScript initialization failure in the original package and expands the editing UI.

## Working editor features
- Video import + drag/drop
- Multi-clip timeline, split, reorder and delete
- Trim handles and playhead start/end
- Speed + speed ramps
- Brightness, contrast, saturation and expanded visual effects
- Caption builder, manual timed captions, browser speech recognition and API transcription hooks
- Caption presets, word highlighting and animated captions
- Built-in sticker library with 60+ original/reusable emoji-symbol sticker choices, categories and animations
- Text stickers and image stickers
- Drag stickers directly on the preview
- PIP / overlay image or video, opacity, blend modes and masks
- Chroma key / green-screen mode
- Background removal mode using MediaPipe when online
- Music track, volume and generated SFX
- Voice enhancement with EQ, compressor, noise gate and limiter
- Beat detection + beat pulse
- Pro canvas: 9:16 / 1:1 / 16:9 / 4:5, zoom, rotation, position, opacity, mirror and contain/cover
- Canvas background
- Browser export through MediaRecorder (MP4 where supported, otherwise WEBM)

## Important
The built-in sticker pack is intentionally made from original symbols/emoji rather than copying Instagram, YouTube or other platforms' proprietary sticker artwork. Internet APIs such as Whisper/Groq/Pexels require your own keys.

Serve over HTTPS or localhost for the best browser capabilities.
